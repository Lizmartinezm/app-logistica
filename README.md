# app-logistica

App web para generar programaciones de entregas y recogidas desde un archivo Excel.

## Funciones iniciales

- Subir la base de datos en Excel.
- Filtrar por fecha y ciudad.
- Separar entregas y recogidas.
- Ver la programacion en pantalla.
- Descargar la ruta en Excel.
- Descargar la ruta en PDF.

## Como usar

1. Abrir `index.html` en el navegador.
2. Subir el archivo `Base de datos.xlsx`.
3. Escoger fecha y ciudad.
4. Presionar `Generar ruta`.
5. Descargar Excel o PDF.
