# app-logistica

App web para generar programaciones de entregas y recogidas desde un archivo Excel.

## Funciones iniciales

- Subir la base de datos en Excel.
- Filtrar por fecha y departamento.
- Separar entregas y recogidas.
- Ver la programacion en pantalla.
- Cargar una ruta anterior para recuperar observaciones y estado.
- Editar observaciones y estado antes de descargar.
- Descargar la ruta en Excel.
- Descargar la ruta en PDF.

## Como usar

1. Abrir `index.html` en el navegador.
2. Subir el archivo `Base de datos.xlsx`.
3. Opcional: subir una ruta anterior ya editada.
4. Escoger fecha y departamento.
5. Presionar `Generar ruta`.
6. Editar observaciones y estado directamente en la tabla.
7. Descargar Excel o PDF.
